# Leandro Moto Peças - Sistema Web

Site institucional e catálogo online para oficina mecânica e venda de peças da Leandro Moto Peças.

## Funcionalidades implementadas

- Página inicial com apresentação da empresa e CTA para WhatsApp.
- Sessão de serviços da oficina.
- Catálogo de peças com preços e carrinho de compras.
- Simulação de finalização de compra com Pix, cartão de crédito e débito.
- Formulários de cadastro e login de clientes.
- Formulário para solicitação de orçamento.
- Área administrativa simulada para gestão de produtos.
- Layout responsivo para desktop, tablet e celular.

## Tecnologias

- HTML5
- CSS3
- JavaScript (vanilla)

## Como executar

Abra o arquivo `index.html` em qualquer navegador moderno.
